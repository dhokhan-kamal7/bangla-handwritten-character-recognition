# Bangla Handwritten Character Recognition

## Project Overview

Bangla Handwritten Character Recognition is a machine learning-based project focused on recognizing handwritten Bangla characters using deep learning techniques.

The project aims to explore how artificial intelligence and computer vision can be applied to handwritten Bangla text recognition. It uses image processing and a Convolutional Neural Network (CNN) to identify handwritten characters from input images.

## Objectives

- Develop a deep learning model for Bangla handwritten character recognition.
- Explore image preprocessing techniques for handwritten character images.
- Train and evaluate a CNN-based classification model.
- Provide an interactive interface for handwritten character input and prediction.
- Track model training experiments and performance.

## Dataset

The project uses the **BanglaLekha-Isolated** dataset, which contains approximately 166,105 handwritten character images distributed across 84 character classes.

Dataset source: [BanglaLekha-Isolated – Mendeley Data](https://data.mendeley.com/datasets/hf6sf8zrkc/2)

- Handwritten Bangla character classification.

## Project Scope

The current implementation focuses primarily on isolated handwritten character recognition. It provides a foundation for exploring more advanced Bangla handwriting recognition systems.

## Limitations

- The dataset focuses on isolated characters rather than complete handwritten words.
- Prediction performance may vary depending on handwriting style and image quality.
- Accurate full-word recognition requires additional word-level data and more advanced recognition techniques.

## Future Improvements

- Improve recognition accuracy and model performance.
- Extend recognition capabilities to complete Bangla words and sentences.
- Explore sequence-based handwriting recognition architectures.
- Improve image preprocessing and segmentation techniques.
- Evaluate the model on a wider variety of handwriting samples.
